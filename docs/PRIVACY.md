# Privacy Policy

**Last Updated**: January 2025

## Introduction

Taxzy.ai ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our service.

## Information We Collect

### Personal Information

When you register for Taxzy.ai, we collect:
- **Name**: Your full name
- **Email Address**: For account authentication and communication
- **Password**: Securely hashed and stored
- **Visa Type**: To provide relevant tax information
- **University** (optional): For context in responses

### Usage Information

We automatically collect:
- **Conversation History**: Questions asked and responses received
- **Session Data**: Login times, session duration
- **Device Information**: Browser type, IP address, device type
- **Usage Patterns**: Features used, pages visited

### Technical Information

- **Log Data**: Server logs for debugging and security
- **Cookies**: Session management and preferences
- **Analytics**: Usage statistics (anonymized)

## How We Use Your Information

### Primary Uses

1. **Service Delivery**
   - Provide tax information and assistance
   - Maintain conversation history
   - Personalize responses based on visa type

2. **Account Management**
   - Authenticate users
   - Manage user accounts
   - Send important updates

3. **Service Improvement**
   - Analyze usage patterns
   - Improve AI accuracy
   - Debug technical issues
   - Develop new features

4. **Security**
   - Detect and prevent fraud
   - Protect against security threats
   - Enforce our terms of service

## Data Sharing and Disclosure

### We Do NOT Share Your Data With:
- Third-party advertisers
- Data brokers
- Marketing companies
- Other users

### We May Share Data When:
- **Required by Law**: Court orders, subpoenas, or legal obligations
- **Service Providers**: Trusted partners who help operate our service (e.g., hosting providers)
  - MongoDB Atlas for database hosting
  - Cloud providers (AWS/Azure)
- **Business Transfers**: In case of merger, acquisition, or sale
- **Your Consent**: When you explicitly authorize sharing

### Service Providers

We use the following third-party services:
- **MongoDB Atlas**: Database hosting
- **Hugging Face**: LLM API services
- **Cloud Hosting**: AWS or Azure for infrastructure

All service providers are bound by confidentiality agreements and data protection regulations.

## Data Security

### Security Measures

We implement industry-standard security practices:

1. **Encryption**
   - Data in transit: TLS/HTTPS
   - Data at rest: Database encryption
   - Password hashing: bcrypt

2. **Access Control**
   - JWT authentication
   - Role-based access
   - Session management

3. **Infrastructure Security**
   - Firewall protection
   - Regular security updates
   - Intrusion detection
   - Regular backups

4. **Application Security**
   - Input validation
   - XSS protection
   - CSRF protection
   - Rate limiting

### Data Retention

- **Active Accounts**: Data retained while account is active
- **Deleted Accounts**: Data permanently deleted within 30 days
- **Backups**: Removed from backups within 90 days
- **Logs**: Server logs retained for 30 days
